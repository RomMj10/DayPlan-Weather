# DayPlan-Weather API

Weather & Outdoor Activity Suggestion API

Turn raw weather data into actionable daily plans—what activities to do, what to avoid, 
and how to stay safe based on real-time weather conditions.


## Endpoints

`http://localhost:3000/v1/weather/current?city=cebu/` - Get the current weather conditions from a specific city

`http://localhost:3000/v1/weather/forecast?city=cebu&days=3` - Get the weather forecast from a specific city with a number of days
