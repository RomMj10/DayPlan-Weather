# DayPlan-Weather API

Weather & Outdoor Activity Suggestion API

Turn raw weather data into actionable daily plans—what activities to do, what to avoid, 
and how to stay safe based on real-time weather conditions.


## Endpoints

`/v1/weather/current?city=cebu/` - Get the current weather conditions from a specific city

`/v1/weather/forecast?city=cebu&days=3` - Get the weather forecast from a specific city with a number of days

`v1/activities/suggestions?city=cebu` - Get activity suggestions based on the weather conditions of the city
